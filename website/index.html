ReviewDesk

커밋과 브랜치를 AI로 리뷰하는 데스크톱 Git 클라이언트

macOS용 다운로드

Apple Silicon Mac 전용 · 약 530MB

할 수 있는 일

  • 선택한 커밋이나 현재 브랜치의 변경사항을 AI로 리뷰
  • 지난 리뷰를 커밋, 메시지, 브랜치로 검색해서 다시 보기
  • 프로젝트별로 에이전트, 모델, 리뷰 프롬프트 설정
  • 커밋 목록에서 브랜치가 갈라지고 합쳐지는 흐름을 그래프로 확인

설치

  1. 다운로드한 zip의 압축을 풉니다.
  2. ReviewDesk.app을 응용 프로그램 폴더로 옮깁니다.
  3. 응용 프로그램 폴더에서 실행합니다.

실행 중에는 앱을 옮기지 마세요. 옮기면 Git을 찾지 못해 동작하지 않습니다. 옮겼다면 앱을 완전히 종료하고 다시 실행하세요.

"확인되지 않은 개발자" 경고가 나올 때

이 앱은 Apple 공증을 받지 않아서 처음 실행할 때 macOS가 막을 수 있습니다. 출처를 신뢰하신다면 시스템 설정 → 개인정보 보호 및 보안에서 그래도 열기를 누르거나, 터미널에서 아래 명령을 실행한 뒤 다시 여세요. 

xattr -dr com.apple.quarantine /Applications/ReviewDesk.app

AI 리뷰를 쓰려면

ReviewDesk는 컴퓨터에 설치된 에이전트 CLI를 실행합니다. API 키는 필요 없고, Claude Code를 설치하고 터미널에서 로그인해 두면 됩니다. 리뷰할 커밋 로그와 diff는 그 에이전트의 서비스로 전송됩니다.

ReviewDesk는 GitHub Desktop을 기반으로 한 개인 포크이며, GitHub의 공식 제품이 아닙니다. GitHub은 이 앱을 보증하거나 지원하지 않습니다. 앱 안에는 GitHub Desktop 문구가 남아 있습니다.
