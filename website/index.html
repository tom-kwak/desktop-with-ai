AI 리뷰가 들어간 Git 클라이언트

히스토리를 읽고,
커밋을 AI로 리뷰하세요

GitHub Desktop의 기능은 그대로 쓰면서, 커밋과 브랜치를 AI로 리뷰하고 GitLab 머지 리퀘스트까지 다루는 데스크톱 Git 클라이언트입니다.

macOS용 다운로드 설치 안내

Apple Silicon Mac 전용

Quick Start

curl -L https://github.com/tom-kwak/desktop-with-ai/releases/latest/download/ReviewDesk-arm64.zip -o /tmp/ReviewDesk.zip && unzip -oq /tmp/ReviewDesk.zip -d /Applications && xattr -dr com.apple.quarantine /Applications/ReviewDesk.app

터미널에 붙여 넣으면 최신 버전이 설치됩니다. 앱이 실행 중이면 먼저 종료하세요.

GitHub Desktop 기능은 그대로 동작합니다

커밋, 브랜치, 푸시와 풀, 머지와 리베이스, 스태시, 충돌 해결까지 GitHub Desktop에서 하던 작업은 같은 화면, 같은 방식으로 씁니다. 새 기능은 기존 화면에 더해진 것이라, 쓰지 않으면 평소와 똑같습니다.

앱 이름이 달라서 GitHub Desktop과 나란히 설치할 수 있습니다.

GitHub Desktop에 더한 기능

히스토리를 읽고 리뷰하는 데 필요한 것을 더했습니다

GitHub Desktop을 기반으로 하고, 아래 기능이 새로 들어갔습니다. 화면은 모두 실제 앱입니다.

NEW

브랜치의 흐름이 보이는 히스토리

커밋 목록 왼쪽에 브랜치가 갈라지고 합쳐지는 그래프가 붙습니다. GitHub Desktop의 히스토리는 커밋을 한 줄씩 나열할 뿐입니다.

  • 커밋을 선택하면 같은 브랜치에서 만든 커밋만 강조됩니다.
  • 브랜치 끝 커밋에 브랜치 이름 칩이 붙습니다.
  • 현재 브랜치의 커밋에는 점 둘레에 링이 표시됩니다.
NEW

브랜치별, 커밋별로 리뷰합니다

커밋 하나만 볼지, 브랜치 전체를 볼지 고를 수 있습니다. 결과는 마크다운으로 정리되어 바로 읽을 수 있습니다.

  • Review 1 commit 선택한 커밋의 변경사항을 리뷰합니다.
  • Review branch 현재 브랜치의 변경사항을 한 번에 리뷰합니다.
  • 컴퓨터에 설치된 Claude Code, Codex CLI, Gemini CLI를 실행하고, 에이전트와 모델은 직접 고릅니다.
  • 저장소 파일 읽기를 켜면 diff 밖의 코드도 참고합니다(Claude Code만).
NEW

리뷰 템플릿을 내 방식대로

리뷰 프롬프트를 템플릿으로 저장하고 바꿀 수 있어서, 팀이나 프로젝트의 기준에 맞는 리뷰를 받습니다.

  • 프롬프트에 이름을 붙여 여러 개를 만들고, 리뷰할 때 고릅니다.
  • 기본 프롬프트도 수정할 수 있고, 언제든 처음 상태로 되돌립니다.
  • 리뷰 창 위쪽에 어떤 에이전트, 모델, 프롬프트로 리뷰했는지 표시됩니다.
NEW

리뷰 히스토리를 관리합니다

받은 리뷰는 앱 안에 저장되어, 나중에 다시 찾아보고 정리할 수 있습니다.

  • Past reviews 지난 리뷰를 모아 보고, 커밋, 메시지, 브랜치로 찾습니다.
  • 같은 커밋의 리뷰가 여러 번이면 History 목록에서 골라 비교하고, Review again으로 다시 받습니다.
  • 필요 없는 리뷰는 지워서 정리합니다.

GitLab 연동

GitLab 머지 리퀘스트를 데스크톱에서 리뷰하고 머지합니다

GitHub 기능과 나란히 GitLab을 씁니다. 브라우저를 오가지 않고 앱 안에서 MR을 만들고, 리뷰하고, 머지합니다.

PAT로 로그인

gitlab.com과 사내 GitLab 서버에 개인 액세스 토큰으로 로그인합니다.

  • 서버마다 계정 하나씩, 여러 서버를 함께 씁니다.
  • 토큰은 macOS 키체인에만 저장합니다.
  • 설정에서 켜야 나타나고, 끄면 GitHub Desktop과 같습니다.

클론과 Git 인증

Clone 대화상자의 GitLab 탭에서 내 프로젝트를 그룹별로 보고 클론합니다.

  • clone, fetch, push에 토큰을 자동으로 써서 비밀번호를 묻지 않습니다.
  • 저장소가 GitLab 프로젝트면 툴바에 Merge Requests 버튼이 생깁니다.

머지 리퀘스트 만들기와 찾기

현재 브랜치로 MR을 만들고, 상태와 사람별로 걸러 봅니다.

  • 제목과 설명(커밋 목록)을 미리 채우고 Draft, 리뷰어를 고릅니다.
  • 이미 열린 MR, 푸시 안 된 브랜치처럼 만들 수 없는 이유를 미리 알려 줍니다.
  • Open, Merged, Closed, 내가 만든 MR, 리뷰 요청된 MR로 거릅니다.

코멘트와 리뷰

설명과 코멘트를 markdown으로 보고, 스레드에 답하고 resolve합니다.

  • Changes 탭에서 줄을 골라 코멘트를 답니다.
  • 코멘트를 리뷰 초안으로 모아 한 번에 제출합니다.
  • 승인, 리뷰 요청, 커밋 추가 같은 기록을 타임라인으로 봅니다.

승인과 머지

승인하고, 머지 가능 여부를 확인한 뒤 바로 머지합니다.

  • 파이프라인 상태와 머지를 막는 이유를 한 줄로 보여 줍니다.
  • squash, 소스 브랜치 삭제 옵션으로 머지하고, 파이프라인이 도는 중이면 자동 머지합니다.
  • 필요하면 GitLab에서 리베이스합니다.

편하게 쓰는 편집기

코멘트와 설명을 GitLab처럼 쓰고 미리 봅니다.

  • Write / Preview 탭과 서식 버튼, ⌘B ⌘I ⌘K 단축키.
  • 목록을 Enter로 이어 쓰고, ⌘Enter로 올립니다.
  • !12, #3, @user를 GitLab 링크로 바꿔 보여 줍니다.

설정 > Accounts > GitLab에서 Enable GitLab integration을 켜고 토큰(api 권한)으로 로그인하면 시작됩니다. MR 창은 GitLab 색을 쓰고 다크 테마를 지원합니다.

설치

설치 안내

Apple Silicon(M1 이상) Mac 전용입니다. 위의 Quick Start 명령은 최신 버전을 받아 /Applications에 설치하고, macOS의 "확인되지 않은 개발자" 경고를 건너뛰도록 격리 표시를 지웁니다. 업데이트할 때도 같은 명령을 씁니다.

직접 설치하려면
  1. zip을 받아 압축을 풉니다.
  2. ReviewDesk.app을 응용 프로그램 폴더로 옮겨 실행합니다.
  3. macOS가 막으면 시스템 설정 → 개인정보 보호 및 보안에서 그래도 열기를 누르거나, 터미널에서 아래 명령을 실행한 뒤 다시 여세요. 
xattr -dr com.apple.quarantine /Applications/ReviewDesk.app

실행 중에는 앱을 옮기지 마세요. 옮기면 Git을 찾지 못해 동작하지 않습니다. 옮겼다면 앱을 완전히 종료하고 다시 실행하세요.

AI 리뷰를 쓰려면

ReviewDesk는 AI 모델을 직접 호출하지 않고, 컴퓨터에 설치된 에이전트 CLI를 실행해서 리뷰합니다. 아래 중 하나를 설치하고 터미널에서 로그인해 두세요. 앱에 API 키를 입력할 필요는 없습니다.

  • Claude Code
  • Codex CLI
  • Gemini CLI

리뷰할 커밋 로그와 diff는 선택한 에이전트의 서비스로 전송됩니다. 설정에서 저장소 접근을 켜면 저장소의 파일 내용도 함께 읽힐 수 있습니다(Claude Code에서만 지원).

Intel Mac과 Windows용 빌드는 제공하지 않습니다.

ReviewDesk는 GitHub Desktop을 기반으로 한 개인 포크이며, GitHub의 공식 제품이 아닙니다. GitHub은 이 앱을 보증하거나 지원하지 않습니다. 앱 안에는 GitHub Desktop 문구가 남아 있습니다.
